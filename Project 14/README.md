# Project 14 - Automated Kubernetes Deployment

This folder is reserved for Practical 14: automating the Wine Quality Prediction Kubernetes deployment using GitHub Actions.

Planned flow:

GitHub commit
→ CI build and test
→ GHCR image
→ self-hosted GitHub Actions runner
→ Minikube/Kubernetes deployment
→ rollout verification
→ health/prediction verification
→ rollback on deployment verification failure

Status: implementation not completed yet. This README only establishes the Project 14 folder.
